## Methodology & disclosures

### How the site is built

OpenAlameda is built with agentic development tools (AI coding agents). A person reviews every change through an ordinary pull request before it ships.

### No AI at runtime

The site itself uses no AI. Every figure comes from a deterministic query over public data.

### Data sources

Campaign finance data comes from the <a href={SOURCE_URL}>City of Alameda campaign disclosure portal (Granicus CampaignDocs)</a>.

### What is excluded

Details arrive with the elections explorer.
