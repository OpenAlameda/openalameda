# OpenAlameda

OpenAlameda gathers and shares data and visualizations so folks can explore, learn, create, and share interesting views of our island and its businesses, government, and people.

The site lives at [openalameda.org](https://openalameda.org). It is a Next.js app deployed on Vercel. The code is MIT licensed, and the data it shows is public record.

Developer commands and repository conventions are in [AGENTS.md](AGENTS.md).

Questions or corrections: info@openalameda.org, or open an issue on GitHub.
