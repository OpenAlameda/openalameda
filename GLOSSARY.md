# OpenAlameda

A site that gathers and shares civic data about Alameda, California, for residents who are curious but not data-savvy.

## Language

**View**:
One state of a page, such as a chosen filter or chart. Its full state lives in the URL, so every view is shareable.
_Avoid_: Screen, page state

**Share preview**:
The title, description and image a link unfurler shows for a URL, rendered on the server.
_Avoid_: Link card, thumbnail

**Default card**:
The preview image every route uses until a view supplies its own: wordmark, page title and accent colour.
_Avoid_: Fallback image, banner

**Page frame**:
The header, footer and content column shared by every page.
_Avoid_: Layout, shell

**Methodology & Disclosures**:
The part of the About page that says how the site is built, where data comes from, what is excluded and how to report an error.
_Avoid_: Disclaimer
